# 🛠️ Unity-MCP Pro: AI Editor Assistant

Transform Unity into an agentic playground. This project allows AI models (like Claude, Gemini, or GPT) to control the Unity Editor directly—spawning objects, modifying materials, compiling custom C# scripts, inspecting component properties reflectively, and building UI in real-time.

---

## ⚡ Quick Start

### 1. Installation
1.  **Download** this repository.
2.  **Double-click** `setup.bat`. This will install all dependencies and show you a code snippet.

### 2. Unity Setup
1.  Copy the `UnityScripts` folder into your Unity project's `Assets` folder (it's recommended to place it under `Assets/Editor/` or `Assets/`).
2.  In Unity, go to **Window > AI > Unity MCP Pro**.
3.  Click **ESTABLISH LINK (START)**.

### 3. AI Client Setup
1.  Copy the JSON snippet generated by `setup.bat`.
2.  Paste it into your AI client's configuration file (e.g., Claude Desktop).

## 🤖 Consolidated Capabilities

- **3D Modeling & Prefabs:** Spawn primitives or instantiate prefabs from your Asset Database at custom coordinates.
- **Transformations:** Move, rotate, and scale any object in the scene.
- **Materials:** Change colors (RGBA) and smoothness/glossiness.
- **Physics & Components:** Add components like `Rigidbody`, `BoxCollider`, or `Light` reflectively.
- **UI System:** Automatically build Canvases, Buttons, Images, and Text labels.
- **Deep Reflection Power:** Inspect any GameObject's components and list all of their public fields, properties, types, and values. Set any field or property on any component using reflection.
- **C# Script Injection:** Generate, write, and compile C# scripts dynamically at runtime from your LLM agent.
- **Visual Reasoning:** Capture SceneView camera renders directly into inline Base64 PNG frames for visual reasoning models.
- **Game Master Controls:** Expose custom RPG runtime controls like player state, spawner presets, dialogue triggers, events, and asset searching.

## 📁 Repository Structure
- `unity-mcp-server/`: The Node.js MCP server (The "Brain").
- `UnityScripts/`: The C# bridge script for the Unity Editor (The "Hand").
- `setup.bat`: One-click installer for Windows.
- `get-config.js`: Utility to generate your local configuration paths.
