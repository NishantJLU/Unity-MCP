# 🛠️ Unity-MCP Pro: AI Editor Assistant

Transform Unity into an agentic playground. This project allows AI models (like Claude, Gemini, or GPT) to control the Unity Editor directly—spawning objects, modifying materials, adding physics, and building UI in real-time.

---

## ⚡ Quick Start

### 1. Installation
1.  **Download** this repository.
2.  **Double-click** `setup.bat`. This will install all dependencies and show you a code snippet.

### 2. Unity Setup
1.  Copy the `UnityScripts` folder into your Unity project's `Assets` folder.
2.  In Unity, go to **Window > AI > Unity MCP Bridge**.
3.  Click **Start Bridge**.

### 3. AI Client Setup
1.  Copy the JSON snippet generated by `setup.bat`.
2.  Paste it into your AI client's configuration file (e.g., Claude Desktop).

---

## 🤖 Capabilities

- **3D Modeling:** Spawn primitives (Cubes, Spheres, etc.) with custom names and positions.
- **Transformations:** Move, rotate, and scale any object in the scene.
- **Materials:** Change colors (RGBA) and smoothness/glossiness.
- **Physics:** Add components like `Rigidbody`, `BoxCollider`, or `Light`.
- **UI System:** Automatically build Canvases, Buttons, and Text labels.
- **Reflection Power:** Modify *any* public property on *any* component using the `set_unity_property` tool.
- **Hierarchy:** Parent and group objects programmatically.

---

## 📁 Repository Structure
- `unity-mcp-server/`: The Node.js MCP server (The "Brain").
- `UnityScripts/`: The C# bridge script for the Unity Editor (The "Hand").
- `setup.bat`: One-click installer for Windows.
- `get-config.js`: Utility to generate your local configuration paths.
